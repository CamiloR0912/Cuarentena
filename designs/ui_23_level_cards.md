# ui_23 — Level title cards

| Field | Value |
|---|---|
| Priority | **P3** (polish) |
| Used in | Shown 2 s when a level starts, and as the image in the level briefing |
| Output folder | `juego/assets/ui/levels/` |

## Description

One small illustration per level, **240×135** (a 16:9 thumbnail), framed with `panel_dark`, with the level name below in the large font.

| File | Level | Scene |
|---|---|---|
| `level_1_barrio.png` | Nivel 1 — El barrio | Empty residential street with fog, abandoned taxi, quarantine tape, Elena leaving her building door |
| `level_2_hospital.png` | Nivel 2 — Hospital San Rafael | Hospital entrance at night with ambulances and a red-cross sign, a line of patients at the door |
| `level_3_centro.png` | Nivel 3 — El centro | Plaza de Bolívar with the cathedral, a swarm (Masa) crossing the plaza, abandoned checkpoint |
| `level_4_laboratorio.png` | Nivel 4 — El laboratorio | University corridor ending in the auditorium doors, glowing green light leaking from inside |

All single frame, opaque, palette Cuarentena-36.
